# Reference examples

Các sketch trong thư mục này là những ví dụ chi tiết từ các bản trước.
Chúng được giữ lại để tra API/debug nâng cao nhưng không nằm trong menu Arduino IDE chính.

Để bắt đầu project mới, dùng:

- `examples/ControllerTemplate`
- `examples/Diagnostics`
- `examples/ConnectionModes`
